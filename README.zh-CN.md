## 侧栏使用

- 输入区只保留 **+、执行/规划、模型、发送/停止**。`+` 分开提供“引用整篇当前笔记”和“仅引用当前选区”，也可浏览外部资料、选择 Skill 或生成可视化。点击引用标签预览实际范围；仅选区不会附带同篇笔记全文，Agent 后续读取仍由工具权限控制。
- 在光标处输入 `@` 搜索笔记；`/` 查看命令。方向键选择，Enter 确认，Escape 关闭。Enter 发送，Shift+Enter 换行，中文输入法组词时不会发送。
- 每个会话独立保存草稿、引用、选区、Skills 和外部资料引用。新会话为空白；恢复会话取回其上下文。
- 长对话先显示最近 100 条展示记录，可向上加载更早内容。后台回复保留阅读位置，主动发送或“回到最新”回到末尾。
- 编辑消息时先展示编辑框；确认后才创建分支并发送，取消不改变会话。分支保留原会话，已有文件修改不会随分支自动回退。
- 运行时显示阶段和耗时。继续输入可加入队列，或立即引导。任务失败会暂停队列，已经尝试过的任务不会盲目重发。
- 每轮指令旁可打开对应文件变更。底部审阅入口可切换本轮、当前对话和全部记录，查看差异、打开文件或进入撤销预览。

## Agent 做错后撤销

**更多选项 → 最近操作与撤销 → 预览撤销这一轮 → 确认撤销**。

记录最近的 Agent 文件操作，不需要 Git，不扫描整个笔记库。支持修改、新建、移动、重命名、删除及已授权外部文本文件。撤销前和执行时都会核对文件；人工后续修改会触发冲突。撤销新建会保留恢复副本。对话消息不删除。完整边界见 [操作恢复说明](docs/OPERATION-RECOVERY.md)。

旧 Git 历史只在高级设置中手动使用；正常任务和操作撤销不依赖它。

## 连接、模型与权限

本机验证基线：Obsidian 1.14.4、OpenCode 1.19.0、Windows。开发使用 Node.js 20+。Linux 原仓库功能和提交不在本轮范围。

首次使用按 [Windows 安装引导](docs/GETTING-STARTED-WINDOWS.md) 安装固定版本 OpenCode 1.19.0。连接页提供下载入口、选择可执行文件和自动检测；高级路径与接口字段可折叠。普通用户不需要 Node.js。**应用并测试本地连接** 检查本地服务；供应商鉴权和远程模型需要首条回复验证。

API Key 可选择“仅本次运行”或“保存在本机，下次继续使用”。长期配置通过 OpenCode 本机凭据接口保存，不写入插件数据或笔记库；它是 OpenCode 的凭据文件，不是操作系统加密密码库。保存成功后清空输入框；可检查已保存凭据并在重启后复用。侧栏切换模型会同步到未修改的设置字段；有冲突草稿时禁止保存，并提供载入当前配置的按钮。

模型按钮可搜索近期模型、读取 OpenCode 目录或输入模型 ID，应用时重连本地服务。目录可显示推理能力和上下文长度；目录登记不代表远程可用。运行中的任务禁止切换模型和会话。规划模式只读；执行模式遵守逐项权限。权限预设根据实际权限显示，手工修改后自动显示为自定义。

询问式权限在对话内显示目标和修改差异，只授权一次，120 秒后自动拒绝。停止任务、关闭审批或关闭视图也会拒绝。

## 资料、Skills 与成果

资料面板分为资料、Skills、工作目录三个页签。目录默认只读；可浏览文本、查看单文件预览并引用到当前对话。重新读取时仍检查授权和大小。选择系统目录后点击添加；如果当前 Electron 环境未提供目录选择器，可粘贴绝对路径。目录和 Skill 路径草稿在切换页签后保留，保存值与显示值一致。

外部写入需在工作目录页单独开启，工具仍受权限和恢复日志约束。Skill 只有显式选择后才加入上下文，不会自动运行其中脚本。

交互卡需要 Dataview 并开启 JavaScript 查询。运行入口提供权限说明和代码预览，用户主动点击才执行。运行状态和错误显示在卡片内；保存后按钮变为打开已保存笔记，不重复新建。DataviewJS 具有 Obsidian 的执行权限，不是隔离沙箱。

## 联网、账号与文件访问

插件采用 MIT 许可，免费使用。DeepSeek 需要供应商账号、API Key 和可用 API 额度，模型费用由供应商收取；插件没有单独订阅。发送请求时，本机 OpenCode 会把对话、引用的笔记或选区、所选 Skill、外部资料及授权工具结果发送至你配置的模型服务。移除引用不会删除已经发送的内容。发送私人资料前请核对供应商的数据处理条款。

插件仅在显式选择后读取外部资料目录与 Skills；外部写入需要单独授权。OpenCode 可执行文件与本机凭据保存在笔记库之外，本地连接使用回环地址和认证。OpenCode 是单独的应用，有自身配置与联网行为。插件不采集分析或遥测，不自动安装或更新依赖；可选安装脚本由用户手动运行。交互卡的 DataviewJS 代码有宿主权限，可在点击运行前查看。

## 原位更新

先构建，再用更新器指定**已经存在的插件目录**及**插件目录外的备份位置**：

```text
node build.cjs
node scripts/install.cjs "<插件目录>" "<备份目录>"
```

更新器保留旧 ID（包括 `obsidian-agent-demo`）、`data.json` 和 `runtime/history.git`。只备份并替换 `main.js`、`manifest.json`、`styles.css`，核对哈希后输出报告。更新完成后重载插件。本机实际安装使用 `vault-bridge`。

本地交付包通过 `node scripts/package.cjs` 生成到 `dist/0.7.4/`；包含三个发布文件和源码/发布文件 SHA-256 清单。Windows CI 从干净检出构建、回归并上传候选包，版本 tag 自动准备草稿 Release。API Key、用户笔记、插件运行数据与 Git 历史不进入交付包。
